# CSCI-319

#Startup guide
-run python main.py
------------------
##Controls
- Move with WASD or Arrow Keys
- Dash with Space
- Melee attack with Left Mouse Button
- Shoot arrows with Right Mouse Button
- Pause with P
- Toggle collision debug with F3
- Quit with Esc
--------------
##Known Bugs / Current Limitations
Enemies can sometimes get caught on map obstacles while pathing.
In stage two, the boss can occasionally get stuck in a dash state while mostly stationary because of getting caught into an obstacle(had to attack to reset).
Rapid arrow spam is currently possible. This was intentionally not fixed yet because the high rate of fire can be used as a crutch to clear harder late stage encounters. This is a temporary tape over, as i originally intended to have modifiers to projectiles to help clear big waves of enemies.
